# 个人 AI 开发日志

每位成员在本目录创建并只维护自己的日志文件：

```text
docs/dev-logs/<github-username>.md
```

每次开发在文件顶部追加一段记录，使用下面的模板。日志的作用是帮助项目负责人和集成 AI 理解修改意图、接口影响和冲突处理要求，不需要写成长篇报告。

```markdown
## YYYY-MM-DD｜本次任务名称

- 分支：`member/<github-username>`
- 最新提交：完成提交后填写短哈希
- 任务目标：

### 已完成

-

### 主要文件

- `路径`：修改原因

### 接口变化

- 新增/修改/无：
- 请求字段：
- 响应字段：
- 错误和状态变化：

### 数据库与数据变化

- 表或字段：
- 坐标系或空间范围：
- 数据来源与处理脚本：

### 配置与依赖变化

- 环境变量：
- Python/npm/Docker 依赖：

### 验证结果

- `[通过/失败/未执行]` 验证命令或操作

### 对其他模块的影响

- 依赖的上游输出：
- 提供给下游的输出：
- 高冲突公共文件：

### 已知问题与下一步

-

### 合并提示

- 可以合并/暂时不要合并：
- 项目负责人需要重点检查：
```

如果本次没有接口、数据库或配置变化，明确填写“无”，不要直接删除对应栏目。
