# GIS 数据目录规则

大体积 GIS 数据不直接提交到 Git。团队共享数据时，应先在 `manifest.example.json` 的副本中登记，再通过课程允许的共享位置分发。

建议的本地目录结构：

```text
data/
  raw/          原始下载文件，只读保存
  interim/      坐标转换、裁剪后的中间成果
  processed/    可入 PostGIS 或供模型使用的数据
  samples/      可提交的小型脱敏样例
```

每个数据集至少记录：名称、来源链接、许可、获取日期、空间范围、时间范围、原始坐标系、目标坐标系、处理步骤和 SHA-256 校验值。

数据库统一使用 EPSG:4326 保存交换几何；距离、面积和栅格分析必须选择适合研究区的投影坐标系，并在处理脚本和报告中记录 EPSG 编码。禁止直接用经纬度单位计算米或平方米。
